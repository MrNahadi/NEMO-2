# Glossary

| Word | Meaning |
| --- | --- |
| ASME BTH-1 | An American standard for designing lifting devices. NEMO uses its rules for plates with pin holes. |
| Base | The bottom edge of the padeye, welded to the deck or structure. |
| CAD | Computer-aided design: drawing parts in 3D on a computer. |
| Cheek plate | A ring of plate welded on each side of the padeye around the hole, to make the hole region thicker. |
| Classification society | An organisation that sets and checks rules for ships, such as DNV, Bureau Veritas, Lloyd's Register or ABS. |
| Design category | ASME BTH-1's grouping of lifts: A for predictable lifts (safety factor 2.0), B for uncertain or rough conditions (3.0). |
| Design factor | The safety factor the rules apply. Capacity = strength / design factor. |
| DXF | A drawing file most cutting tables and 2D CAD programs read. |
| Dynamic factor (DAF) | A multiplier for the extra force from jerks and swinging during a lift. |
| FEA | Finite element analysis: a computer simulation that splits a part into small pieces to work out stresses. |
| Fillet weld | A triangular weld in the corner between two plates. Its size is the length of its legs. |
| FOS | Factor of safety: how many times stronger something is than it needs to be. |
| Head radius | The radius of the rounded top of the padeye, measured from the hole centre. |
| Jaw width | The inside width of a shackle where the pin goes through. |
| kN | Kilonewton, a unit of force. 1 tonne weighs about 9.81 kN. |
| Mesh | The small pieces a part is split into for FEA. |
| MPa | Megapascal, a unit of stress (force per area). 1 MPa = 1 newton per square millimetre. |
| Padeye | A plate with a hole, welded to a structure, for attaching a shackle. Also called a lifting lug. |
| Pin | The bolt of a shackle that passes through the padeye hole. |
| Service class | ASME BTH-1's grouping by how many full-load lifts the padeye will see in its life. |
| Shackle | A U-shaped steel link with a pin, connecting a sling to a padeye. |
| Sling angle | The angle between a sling and the horizontal. 90° is straight up. |
| STEP | A standard 3D file format almost every CAD program can open. |
| Stress | Force spread over an area. Too much stress makes steel bend permanently (yield) or break. |
| Utilization (use) | Demand divided by capacity, as a percentage. Up to 100% passes. |
| Von Mises stress | A single number that combines all the stresses at a point, used to compare with yield strength. |
| WLL | Working load limit: the largest load a shackle or sling is rated to carry. |
| Yield strength | The stress at which steel starts to bend permanently. |
